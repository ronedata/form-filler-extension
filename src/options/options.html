Help

How the pieces fit together.

Quick start

  1. On any page with a form, click the Form Filler icon and press Fill all fields. Most forms fill sensibly with no setup.
  2. Want a particular value in a particular field? Go to Custom fields and press + Add field, or start from Ready-made rules.
  3. Fill the same form again and again? Fill it once by hand, then choose Map this form in the popup.

Matching a field

A rule looks for its words in a field’s name, id, placeholder, label and aria-label, and fills the field if any of them contains one. Open Advanced matching in a rule to compare exactly, use a regular expression, look in other attributes, or point at fields with a CSS selector such as form#checkout input[name^="card"].

Rules are checked from the top. A rule made for one website always beats a rule for every website, so you can keep a general rule and override it on a single site.

Ready-made rules

  • Essentials — names, email, phone, address, comments. Added on install.
  • Bangladesh — BD mobiles, 4-digit post codes, NID, birth registration, board roll, registration no, passing year, GPA.
  • Money and numbers — fees, discounts, received amounts, quantities, kept to sensible ranges.
  • Leave these alone — never touch captchas, OTPs, coupon codes or search boxes. Added at the top, because a rule only protects a field if it is checked first.

Choosing websites

Pick Only these websites in a rule and list them one per line:

  • Domain — example.com also covers app.example.com
  • Wildcard — example.com/signup*, https://*.shop.com/*
  • Regular expression — ^https://(stage|prod)\.acme\.io/

Form maps

A custom field matches by words; a form map pins a value to every field of one specific form, so it comes out identical each time. It beats every custom field rule.

  • When I click into the form — the first click fills the whole form.
  • Automatically when the page loads — no click needed.
  • Only when I ask — from Fill it now in the popup.

Under Advanced: Fill only once each time the page loads stops a map firing on every click, and Only fill when the form is still empty keeps it from overwriting anything you typed.

Dropdowns that depend on each other, and lookups

Every fill — Fill all fields, Fill this form, custom fields and form maps — waits for dropdowns that load after an earlier choice, so chains like Division → District → Thana fill in order. It notices the page reacting, or a loading overlay, and waits until it is done. Turn it off or change the limit under Settings → Dropdowns and suggestion lists; a form map has its own timings under Advanced.

Lookup fields are handled automatically too: when no rule covers the field, Form Filler types a short search and takes a suggestion, so the hidden id behind it gets set. It recognises standard autocomplete boxes and the common pattern of a name box with an empty …Id field beside it.

For a field where you type and pick from suggestions, the most reliable approach is to fill the form by hand, then map it with Remember what is typed in it right now ticked. The map keeps the text and the hidden id the page stored with it.

If you want a fresh lookup each time instead, choose Autocomplete (type, then pick) as the value: say what to type and which suggestion to take.

Value patterns

  • L capital letter · l small letter · C either
  • # digit · * letter or digit · ? any character
  • [3-9] or [013] — one character from that set
  • \ makes the next character literal
  • Bangladeshi mobile: +8801[3-9]######## → +8801712345678

Date format letters: YYYY YY MM M DD D HH H hh h mm ss A a.

Privacy

Form Filler makes no network requests of any kind — nothing it does ever leaves your device. Your rules, saved forms and settings live only in this browser's local storage; if you use "remember what is typed in it right now" while saving a form, those values are stored the same way, locally, never sent anywhere.
